How to use

  1. Enter matching X and Y values, or paste two columns of data.
  2. Review the highlighted cells if validation finds a problem.
  3. Read the fitted line, tables, plots, and statistics below. Use “Show the solution” to follow the arithmetic.
  4. Enter an X value to estimate its Y value. Predictions beyond the observed X range are extrapolations.
Formulas reference

Sxx = Σx² − (Σx)²/n; Syy = Σy² − (Σy)²/n; Sxy = Σxy − (ΣxΣy)/n

Bxy = Sxy/Sxx; Ayx = ȳ − Bxy·x̄; ŷ = Ayx + Bxy·x

r = Sxy/√(Sxx·Syy); r² = r·r; Sy.x = √(SSE/(n−2))

Byx = Sxy/Syy; Axy = x̄ − Byx·ȳ

Covariance shown here is the sample covariance, Sxy/(n−1). Sy.x is defined only for three or more pairs.
